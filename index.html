GUÍA RÁPIDA

De git branch a GitHub

Aprende los comandos esenciales para crear ramas, trabajar en ellas y subir tus cambios a GitHub.

Ver comandos ↓

COMANDOS ESENCIALES

Git Branch

Busca un comando y copia el código que necesitas.

Consultar

Ver ramas

Muestra las ramas existentes en tu proyecto.

git branch
Crear

Crear una rama

Crea una rama nueva sin cambiarte a ella.

git branch nombre-rama
Cambiar

Cambiar de rama

Te mueve a una rama que ya existe.

git switch nombre-rama
Crear + cambiar

Crear y cambiar

Crea una rama y cambia a ella en un solo paso.

git switch -c nombre-rama
Eliminar

Eliminar una rama

Elimina una rama local que ya no necesitas.

git branch -d nombre-rama
Eliminar

Forzar eliminación

Elimina una rama aunque tenga cambios sin fusionar.

git branch -D nombre-rama
Renombrar

Renombrar rama

Cambia el nombre de la rama actual.

git branch -m nuevo-nombre
Remoto

Ver ramas remotas

Muestra las ramas de los repositorios remotos.

git branch -r
Consultar

Ver todas las ramas

Muestra ramas locales y remotas.

git branch -a
Unir

Fusionar una rama

Integra los cambios de otra rama en la actual.

git merge nombre-rama
Actualizar

Actualizar información remota

Descarga referencias nuevas sin modificar tus archivos.

git fetch origin
GitHub

Subir rama a GitHub

Publica tu rama y configura el seguimiento remoto.

git push -u origin nombre-rama
GitHub

Eliminar rama de GitHub

Borra una rama del repositorio remoto.

git push origin --delete nombre-rama

CONCEPTOS

Git vs. GitHub

Git

Es el sistema de control de versiones que funciona en tu computadora. Te permite registrar cambios y trabajar con ramas.

GitHub

Es una plataforma donde puedes alojar repositorios Git, compartir código y colaborar con otras personas.
